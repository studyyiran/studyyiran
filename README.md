# Hi, I'm Yiran · 依然老师

**AI coding educator and developer — building tools that help people learn by making.**

我是依然老师，关注中文 AI 编程教育，以及从课堂实践中生长出来的开发工具。我希望让老师更容易组织创作，让学习者更容易把自己的想法变成可以运行、调试和分享的作品。

## What I build

My work connects **AI coding education**, **OpenClaw tooling**, and **creative learning workflows**. I build command-line tools, browser extensions to the OpenClaw interface, Python services, and reusable teaching skills.

- **Getting started:** cross-platform setup, Windows / WSL2 installation, and agent management.
- **Creating and sharing:** voice input and output, artifact previews, and workspace synchronization.
- **Learning through iteration:** runtime debug capture, version rollback, and session recovery.
- **Reusable teaching workflows:** course task generation, teacher and student views, and template deployment.

## YiranClaw / MyClaw

**OpenClaw tools for Chinese-language AI coding classrooms.**

YiranClaw brings these workflows together. Its core CLI package, **[`@aiyiran/myclaw`](https://www.npmjs.com/package/@aiyiran/myclaw)**, provides the `myclaw` and `mc` commands for environment setup and maintenance, alongside UI extensions and supporting services.

```bash
npm install -g @aiyiran/myclaw
```

我维护 CLI、界面扩展、同步与调试服务，以及课程相关技能。项目重点是降低课堂使用 AI 编程工具的门槛，把作品预览、调试反馈、版本恢复和课程模板串成完整的创作流程。

[Source repository](https://github.com/studyyiran/yiranclaw) · [npm package](https://www.npmjs.com/package/@aiyiran/myclaw)
